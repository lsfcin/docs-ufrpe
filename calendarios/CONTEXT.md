# calendarios
> Calendários da UFRPE em vigor: as datas do ano letivo de cada nível de ensino. Cada um vale para o período no nome.
> spec: none

**O que é um calendário.** O quadro de datas aprovado para um ano letivo: início e fim dos períodos, matrícula, trancamento, defesas, recessos. Não cria regra; marca quando a regra de uma [norma](../normas/CONTEXT.md) se aplica. Só a versão vigente fica aqui: quando sai um calendário novo, o anterior sai.

**Como consultar.** O nome diz de quem é e para que ano vale (`prpg` é a pós-graduação). Na dúvida sobre uma data, vale o PDF oficial, no link do topo de cada documento.
